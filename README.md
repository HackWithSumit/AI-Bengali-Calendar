# AI-Bengali-Calendar
AI Bengali Calendar with Panjika and Holiday features with reminder and widget support
Here is a comprehensive summary of your **Bangla Panjika (বাংলা পঞ্জিকা)** Android application features based on the latest development cycle (v1.8).

---

## 📱 Bangla Panjika (বাংলা পঞ্জিকা) — App Features

### 📅 Core Calendar & Layout

* **Dual-Date Display:** Shows the traditional Bengali date prominently with the corresponding English date clearly displayed underneath.
* **Month Hierarchy:** Displays the Bengali month contextually beneath the current English month.
* **Authentic Panjika Data:** Provides accurate lunar calendar details including **তিথি (Tithi), নক্ষত্র (Nakshatra), পক্ষ (Paksha), যোগ (Yoga), করণ (Karana), চন্দ্র/সূর্য রাশি (Moon/Sun Sign)**, and **ঋতু (Season)**.
* **Compatibility:** Fully optimized to support **Android 12 (API 31) through Android 16 (API 36)**.
* **Design & Theme:** Clean, modern UI built using Material 3 guidelines. Automatically adapts to system **Dark Mode / Light Mode** natively without heavy external skinning.

### ⚙️ Floating Action Menu (⋮)

To keep the main screen clean, all advanced header tools have been consolidated into a single, sleek floating dropdown menu containing:

1. **AI ফিচার (AI Features)**
2. **ছুটির তালিকা (Holiday List)**
3. **রিমাইন্ডার (Reminders)**
4. **পরিচিতি (About Developer)**

---

### ✨ Advanced AI Features

* **Daily Insights:** Features a 3-tab layout providing Tithi-based spiritual guidance, day-specific health tips, Nakshatra-based astrological data, seasonal advice, and real-time festival alerts.
* **Auspicious Times (শুভ সময়):** Evaluates daily Panjika metrics to suggest favorable and unfavorable windows for 6 vital activities: *Marriage, Travel, Business, Construction, Study, and Medical treatments*.
* **Smart Suggestions:** Displays a prioritized 1-to-5 star rating system recommending specific activities or rituals based on the current day's astrological conditions.

---

### 🔔 Smart Reminders & Holiday Countdown

* **Custom & Presets:** Add custom reminders for specific times or quickly select lunar presets like **একাদশী (Ekadashi), পূর্ণিমা (Purnima), and অমাবস্যা (Amavasya)**.
* **Advanced Adjustments:** Includes snooze settings (5/10/15/30 mins), priority tags, and category classification *(উৎসব, পূজা, ব্রত, জন্মদিন, বার্ষিকী)*.
* **Pre-Holiday Warning System:** Schedule automated alerts to trigger well ahead of major events. Choose to be reminded exactly on the day, or **1, 3, 7, 14, or 30 days before** the festival.
* **Persistence:** Reminders automatically reschedule and survive device restarts (Boot Receiver implementation). Requires standard notification permissions on Android 13+.

---

### 🏝️ Verified Holidays (2025–2032)

* **Dynamic Calculations:** Variable-date lunar holidays are calculated dynamically using official gazette and astrological data for 2025–2032.
* **Color-Coded Categories:** 60+ holidays are mapped visually across the grid with dot indicators:
* 🔴 **জাতীয় (National):** Republic Day, Independence Day, etc.
* 🟢 **বাংলা (Bengali Cultural):** Pohela Boishakh, Durga Puja (Shashthi-Dashami), Rabindra Jayanti, Mahalaya, Bhai Phota.
* 🟠 **ধর্মীয় (Religious):** Eid, Janmashtami, Buddha Purnima, Christmas.
* 🔵 **আন্তর্জাতিক (International):** Mother Language Day, Earth Day.
* 🟣 **ঐচ্ছিক (Restricted/Optional):** Specified state holidays.



---

### 🧩 Home Screen Widgets

The app features **3 fully resizable, dark-mode-compatible** widgets localized in Bengali:

1. **পঞ্জিকা (ছোট) — Small (2x1):** A compact look showing today's Bengali date, English date, and weekday.
2. **পঞ্জিকা (মাঝারি) — Medium (3x2):** Displays the current date, active Tithi, Nakshatra, and any running festival.
3. **ছুটির কাউন্টডাউন — Countdown (3x2):** Dynamically grabs the next upcoming Gazetted holiday and shows a countdown timer (e.g., *"আর ৭ দিন পর দুর্গাপূজা"*) using beautiful gradient backgrounds.
